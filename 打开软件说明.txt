雨课堂选择题助手 · Windows 打开方法

1. 下载 ZIP 后，右键选择“全部解压缩”，完整解压到一个方便找到的文件夹。
2. 打开解压后的 RainChoice-main 文件夹。
3. 双击本说明旁边的 RainChoice.exe，即可打开软件，无需安装 Python。
   若隐藏了扩展名，可能只显示 RainChoice，文件类型为“应用程序”。
4. 第一次可以点击“试运行演示”，不需要账号或 API Key。
5. 正式使用：选择平台 → 填写课程编号或链接 → 微信扫码登录
   → 按需配置 AI → 选择运行方式 → 开始监看。

请保留整个文件夹；下次仍然双击 RainChoice.exe 打开。
详细使用方法见同一文件夹内的“使用说明.md”，或 GitHub 仓库页面。
